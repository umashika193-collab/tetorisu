# 手鳥州

Vite・TypeScript・HTML Canvasで制作した、スマートフォン画面向けの落ち物パズルゲームです。1920年代のラバーホースアニメと古い映写フィルムを着想源に、映写技師ジェームスが切り盛りする小さな映画館を描いています。

## Web版・PWA

GitHub Pagesで公開したWeb版は、対応ブラウザーからアプリとしてインストールできます。タイトル画面に「アプリを入れる」が表示された場合はそのボタンを押してください。iPhone・iPadでは共有メニューから「ホーム画面に追加」を選びます。

PWA本体とデフォルトBGMはオフライン利用に備えて保存されます。追加の内蔵曲は初回再生時に通信が必要になる場合があります。更新版は、起動中のゲームを中断しないよう、アプリを閉じて次に開いたときに切り替わります。

## 起動方法

Windowsでは、プロジェクト直下の `PLAY.bat` をダブルクリックしてください。Node.jsのインストールやコマンド入力は不要です。起動後にブラウザーでタイトル画面が開きます。「上映を始める」ボタン、Enterキー、またはSpaceキーでゲームを開始できます。

節目の得点演出を確認するときは `TEST-JAMES.bat` をダブルクリックします。上映開始後に一度自動再生され、その後は画面右下の「ジェームス」「スガーコ」で各キャラクターの演出を繰り返し確認できます。通常のゲームでは節目ごとに25%の確率でスガーコ、75%の確率でジェームスが登場します。テスト操作で実際の得点は変わりません。

終了するときは、同時に開いた「TETORISU Server」のウィンドウを閉じてください。`PLAY.bat` はビルド済みの `dist` を同梱の小さなローカルサーバーで表示します。

同じWi-Fiのスマートフォンで遊ぶ場合は `PLAY-LAN.bat` をダブルクリックし、画面に表示されたNetwork用URLをスマートフォンで開いてください。Windowsファイアウォールの確認が出た場合は、利用中のプライベートネットワークだけ許可します。

## コマンドから起動する場合

Node.js 20.19以上、または22.12以上が必要です。

```bash
npm install
npm run dev
```

起動後、ターミナルに表示されたURL（通常は `http://localhost:5173`）をブラウザーで開いてください。

本番用ビルドの確認:

```bash
npm run build
npm run preview
```

コード品質と自動テストの確認:

```bash
npm run lint
npm run format:check
npm test
```

## キーボード操作

| キー       | 操作                  |
| ---------- | --------------------- |
| 左右矢印   | ミノを左右に移動      |
| 下矢印     | ソフトドロップ        |
| 上矢印 / X | SRSで時計回りに回転   |
| Z          | SRSで反時計回りに回転 |
| スペース   | ハードドロップ        |
| C / Shift  | ミノをホールド        |
| P / Esc    | 一時停止・再開        |
| R          | ゲームを最初から再開  |
| M          | 音響全体のオン・オフ  |

画面下部およびゲームオーバー画面のRESTARTボタンからも再開できます。

## タッチ操作

幅680px以下の画面では、盤面の下にタッチ操作盤が表示されます。左右移動とソフトドロップは長押しに対応し、回転・ハードドロップ・ホールド・一時停止も画面だけで操作できます。

別のタブやアプリへ移動するとゲーム、上映時間、BGM、効果音が自動で一時停止します。画面へ戻った後は「上映を続ける」を押して再開します。

## 自己ベスト

最高得点はブラウザー内へ保存され、タイトル画面とゲームオーバー画面に表示されます。ゲームオーバー時には今回の得点・消去数・レベル・上映時間も確認できます。記録は外部へ送信されません。

## 配布用ZIPを作る

制作者が内容を更新した後は `MAKE_RELEASE.bat` をダブルクリックします。最新のビルドと、Node.jsを必要としない配布用ZIP `release/TETORISU-initial.zip` が作成されます。受け取った側はZIPを展開し、中の `PLAY.bat` をダブルクリックするだけです。

## BGM

タイトル画面またはゲーム画面上部の「伴奏 ♪」を開くと、上映中でも曲を切り替えられます。初期曲は `oto/Коробе́йники.mp3` です。

- `oto` にある5曲から選択（最後に選んだ内蔵曲を保存）
- 音量の調整と伴奏だけの一時停止（設定を保存）
- 約420msのクロスフェードによる曲替え
- 「手持ち曲」から端末内の音声ファイルをBGMとしてループ再生
- Mキーまたは音響ボタンで、効果音とBGMをまとめて消音

手持ち曲はブラウザー内で直接再生され、外部へアップロードされません。ブラウザーの安全上の制約によりファイル自体は保存されないため、ページを開き直した後はもう一度選んでください。対応形式は利用するブラウザーに依存します。

## 実装済み機能

- 10列×20行の盤面
- I / J / L / O / S / T / Z の7種類のミノ
- 7種類を1セットとしてランダムに取り出す7バッグ方式
- 650ms間隔の自動落下
- 壁・床・固定済みミノとの衝突判定
- ミノの固定と次ミノの生成
- Iミノとその他のミノで異なるキック表を使うSRS回転
- 時計回り・反時計回り回転
- ソフトドロップとハードドロップ
- 着地点を示すゴーストピース
- 1ミノにつき1回使用できるホールド
- 接地後500ms、操作によるリセット上限15回のロックディレイ
- 揃ったラインの消去と盤面の繰り下げ
- ライン完成時の発光・ワイプ消去演出
- ライン数に応じた得点計算
- 10ラインごとのレベルアップと落下速度の上昇
- 次ミノのCanvas描画
- 新しいミノを配置できない場合のゲームオーバー判定
- Rキーおよび画面ボタンによるゲーム再開
- P / Escキーと画面ボタンによる一時停止・再開
- タブやアプリを離れた際の自動一時停止
- 長押し対応のスマートフォン向けタッチ操作盤
- 自己ベストの端末内保存と終幕リザルト
- ジェームスとリスを描いたゲーム開始前のタイトル画面
- Web Audio APIで合成するオリジナル効果音（操作・固定・消去・レベルアップ・終幕など）
- 内蔵5曲から選べるループBGM（初期曲はКоробе́йники）
- 手持ち音源のローカル読み込みとクロスフェード切り替え
- BGM音量・休止・選曲の保存
- Mキーと画面ボタンによる音響全体の切り替え・設定保存
- TypeScript strictモード
- ESLintとPrettierによるコード品質管理
- ゲーム基盤の自動テスト
- 縦画面内へ盤面を収めるレスポンシブ表示
- 横画面での縦向き案内
- タッチ時のページスクロール、選択、ピンチ・ダブルタップズームの抑制
- Node.js不要のダブルクリック起動と配布用ZIP作成
- 同じWi-Fiのスマートフォンから遊べるLAN起動

## 今後の候補

- 中断したゲーム状態の保存と復元
- 複数個のNEXT表示
- コンボ、Back-to-Back、Tスピンを含む発展的な得点方式

ミノの自然落下、操作・回転・固定、ライン消去、得点とレベル進行、ゲームオーバーまで遊べる状態です。効果音はブラウザー上でリアルタイム合成し、BGMには `oto` 内の音源または利用者がその場で選んだローカル音源を使用します。
